summary: Follow-up unlock stays disabled after the authorisation is claimed (dashboard, doctor role)
---
A doctor cannot open a follow-up whose authorisation has already been claimed. The unlock control on the examination tab stays disabled, so the case cannot be worked on at all.

## Steps to reproduce

1. Seed a closed case with a claimed follow-up authorisation (fixture `cases:closed_with_claimed_follow_up`).
2. Log in to the dashboard as a doctor who is a member of the case's clinic.
3. Open the case and select the Examination tab.
4. Look at the "Open follow-up" control in the follow-up decision panel.

## Expected

The control is enabled, and activating it opens the follow-up for examination.

## Actual

The control is disabled and its tooltip reads "waiting for authorisation". The API returns the follow-up with `authorisation_claimed_at` set, so the state is correct server side and the dashboard is reading the wrong field.

## Acceptance criteria

- A doctor on a case whose follow-up authorisation is claimed can open the follow-up from the examination tab.
- A doctor on a case whose authorisation is not claimed still sees the control disabled with the existing tooltip.
- The regression is covered by a test at the level where the bug lives.

## Affected surface

Dashboard only. The API response is already correct, confirmed against the serializer output in the reproduction above.

## Out of scope

Anything about follow-up pricing, and the mobile app's own follow-up wizard.
